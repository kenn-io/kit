# Kit v0.37.1

PostHog daily claims retain the 35 most recently accepted UTC dates per
installation, event, and key. Reports compact older history, including on skips.
Returning to a retained date still skips it; a retired date can count again.
Disabled heartbeats start no ticker, and discarded debug logs skip formatting.

## Compatibility

The claims file keeps version 1 and remains readable by released writers.
Upgrade all writers sharing a claims path together. If an old writer's rejected
report leaves cleanup pending, 35 later acceptances can retire its date. After a
clock rollback reuses that date, the old cleanup can delete the new claim and
allow another count.

Unresolved reservations can grow during repeated failures. New dates can still
report, and 35 later known acceptances retire older uncertainty. The 35-date
limit applies to known accepted dates.
